# The terminal, gently

label: terminal

You never have to use the terminal. When you want to, it is a fast way to ask the computer for something by name. Open it with **Ctrl+Alt+T**.

## 5 commands to start with

Type a command, then press enter.

```
pwd
```

Shows which folder you are in.

```
ls
```

Lists what is in that folder.

```
cd Documents
```

Moves into the Documents folder. `cd ..` moves back out.

```
flatpak list
```

Lists the Flatpak apps you have installed.

```
sudo apt update
```

Checks for system updates. `sudo` asks for your password because it changes the system. In the live session it does not ask.

## If a command looks wrong

Press **Ctrl+C** to stop whatever is running. Nothing you type in these 5 commands can harm your files.
