# Install it

label: install

Installing copies Wild & Wired OS onto your computer's disk, so it starts without the USB stick and keeps your files.

## Before you start

1. Back up anything you care about. Installing can erase the disk.
2. Plug the laptop in. An install takes about 15 minutes.
3. Connect to Wi-Fi if you can. It is optional; the installer works offline.

## The steps

1. Double-click **Install Wild & Wired OS** on the desktop.
2. Choose your language, time zone, and keyboard.
3. Keep **Normal Installation** selected.
4. Choose where to install:
   - **Erase disk** replaces everything on the disk with Wild & Wired OS.
   - **Install alongside** keeps Windows and lets you pick a system each time the computer starts. It appears when the disk already has a system on it.
5. Create your user name and password. You type this password to install apps and change settings.
6. Wait for the installer to finish, then restart and remove the USB stick when asked.

## Secure Boot

You can leave Secure Boot turned on. Wild & Wired OS starts with the same signed boot files as Ubuntu.

## After you install

Your system keeps itself up to date through Discover. When updates are ready, a notice appears near the clock. Open it and select **Update All**.
