# Get software

label: software

There is no need to search the web for installers. Discover, the software center, finds, installs, and updates apps for you.

## What is already here

Firefox, LibreOffice, GIMP, Inkscape, Audacity, VLC, KeePassXC, Syncthing, Timeshift, and the everyday KDE apps are installed and work without an internet connection.

## 1-click apps

The Welcome Center and Discover list apps picked for the festival: Krita, Kdenlive, OBS Studio, Thunderbird, and more. Select an app and choose **Install**. These download from Flathub, so they need an internet connection.

## What a Flatpak is

Most apps you add come as Flatpaks. A Flatpak brings everything it needs with it and runs in a sandbox, so an app can only reach the files and devices you allow. You can check what each app is allowed to do with **Flatseal**, which is already installed.

## You downloaded an AppImage. Now what.

An AppImage is a whole app in 1 file. Double-click it and **Gear Lever** opens. Choose **Unlock** and then **Move to the app menu**. The app now appears in your menu like any other, and Gear Lever can update it later.

If double-clicking does nothing, right-click the file, choose **Open With**, and pick **Gear Lever**.
